При скачивании файлом macOS покажет предупреждение. Приложение подписано, но не сертификатом Apple Developer — он платный, и для личной утилиты его нет. Поэтому на всё скачанное браузером система ставит карантинную метку и отказывается открывать. Обходится один раз: правый клик по программе → Открыть → Открыть в диалоге. Команда выше снимает метку сама, поэтому предупреждения не будет.

Что нужно

  • macOS 13 или новее
  • Установленный и залогиненный Claude Code — панель читает его токен из связки ключей, своего входа у неё нет
  • При первом запуске система спросит доступ к связке ключей: нажмите Всегда разрешать

Как пользоваться

  • Панель таскается за любое место, положение запоминается
  • Кнопок на ней нет — всё по правой кнопке: обновить, автозапуск, закрыть
  • Строка состояния сервисов раскрывается кликом: там инциденты Anthropic, если они есть
  • Уведомления приходят на 80% и 95% любого лимита
  • Панель живёт на одном рабочем столе и перетаскивается между ними в Mission Control; если потерялась — откройте программу заново, она придёт к вам

Что она делает с данными

  • Читает токен Claude Code из связки ключей только на чтение, держит в памяти и никуда не записывает
  • Ходит ровно по двум адресам: api.anthropic.com за лимитами и status.claude.com за состоянием сервисов
  • Ни телеметрии, ни аналитики, ни сторонних библиотек
